# ZERO COST AI TRADER — إصدار GitHub Actions التجريبي

هذا المشروع محاكاة **Paper Trading فقط**. يجلب آخر سعر معلن لزوج BTC/USDT من واجهة Binance العامة للقراءة فقط، ثم ينفّذ الصفقات داخل محفظة افتراضية محلية. لا يتصل بحساب تداول، ولا يرسل أوامر مالية، ولا يحتاج مفاتيح API أو إيداع أموال.

## ما الذي تغيّر؟
- أضيف ملف GitHub Actions ليشغّل دورة واحدة كل 5 دقائق (`.github/workflows/paper-trading.yml`).
- أصبحت المحفظة الافتراضية تُحفظ في SQLite، وتُستعاد قاعدة البيانات عبر GitHub Actions cache بين مرات التشغيل.
- يجلب البوت سعر BTC/USDT الحالي من واجهة Binance العامة؛ إذا تعذر الاتصال يتوقف التشغيل دون اختلاق سعر أو تنفيذ صفقة.
- يمكنك تشغيل دورة يدوياً من تبويب Actions عبر زر Run workflow.
- التشغيل المحلي المستمر ما زال متاحاً بالأمر `python main.py`.

## إعداد GitHub خطوة بخطوة (مجاني)

1. أنشئ حساباً في [GitHub](https://github.com/) إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (New repository) واجعله **Public** حتى تستخدم Standard GitHub-hosted runners المجانية.
3. فك ضغط المشروع، ثم ارفع جميع محتويات مجلد `ZERO_COST_AI_TRADER` إلى المستودع. تأكد من رفع المجلد المخفي `.github` أيضاً، وفيه الملف `workflows/paper-trading.yml`.
4. افتح المستودع في GitHub ثم اختر تبويب **Actions**.
5. إذا ظهر زر **I understand my workflows, go ahead and enable them** فاضغطه.
6. افتح سير العمل **Paper Trading Bot**، ثم اضغط **Run workflow** لتجربة أول تشغيل يدوي.
7. افتح التشغيل الذي ظهر وتأكد أن خطوة **Run one paper-trading cycle** انتهت بعلامة خضراء.
8. بعد ذلك سيحاول GitHub تشغيله تلقائياً عند الدقائق 00 و05 و10 و15... بتوقيت UTC. لا يلزم إبقاء الكمبيوتر مفتوحاً.

## تنبيهات مهمة جداً

- هذا ليس خادماً يعمل بلا توقف؛ GitHub يبدأ مهمة قصيرة كل خمس دقائق ثم ينهيها. قد تتأخر الجداول أو تُسقط بعض المهام وقت الضغط.
- الجدولة تعمل على الفرع الافتراضي فقط. وفي المستودعات العامة قد تتوقف تلقائياً إذا لم يحدث أي نشاط في المستودع لمدة 60 يوماً؛ راجع تبويب Actions من وقت لآخر.
- استخدم مستودعاً عاماً لتفادي حدود دقائق المستودعات الخاصة. هذا يعني أن ملفات الكود ستكون مرئية للناس.
- لا تضع كلمات مرور أو مفاتيح API أو بيانات شخصية في ملفات المشروع. هذا الإصدار لا يحتاج أي مفاتيح أصلاً.
- GitHub Actions cache مخصص للتخزين المؤقت وليس قاعدة بيانات دائمة مضمونة. إذا حُذفت الذاكرة المؤقتة أو انتهت صلاحيتها فقد تبدأ المحاكاة من رصيدها الافتراضي من جديد.
- لا توجد ضمانة أن كل تشغيل سيحدث في الدقيقة المحددة، ولا ضمانة لاستمرارية 24/7 الحقيقية.
- لا تستخدم هذا الإصدار بأموال حقيقية. الاستراتيجية تعليمية وغير مثبتة الربحية.

## تشغيله على Windows محلياً

يتطلب Python 3.10 أو أحدث (يفضل 3.11 أو 3.12). افتح PowerShell داخل المجلد ونفّذ:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

لتشغيل دورة واحدة فقط:

```powershell
python main.py --once
```

لتشغيل لوحة التحكم محلياً:

```powershell
streamlit run dashboard/app.py
```

ثم افتح `http://localhost:8501`.

## ما الذي يفعله البوت الآن؟

- يجلب سعر BTC/USDT من واجهة Binance العامة للقراءة فقط.
- يحسب EMA وRSI بعد جمع بيانات كافية.
- ينفّذ شراءً وبيعاً افتراضيين وفق تقاطع المتوسطات.
- يحفظ الأسعار والصفقات والمحفظة الافتراضية في SQLite.

تنبيه: واجهة السعر العامة قد تتعطل أو لا تكون متاحة من بعض الشبكات أو المناطق. عند فشل جلب السعر تتوقف الدورة بأمان. السعر المستخدم هو آخر سعر معلن للزوج وليس بالضرورة سعر تنفيذ يمكن الحصول عليه في تداول حقيقي.
